# Visual references

`Moki_Character_Reference_v0.1.png` records the approved character direction for the prototype: a small cream-and-charcoal companion with long dark ears, a forehead tuft, a dark neck ruff, expressive warm eyes, and a strong readable silhouette.

This image is concept/reference material only. Do not crop it into sprites, ship it in the app bundle, or treat the labels and franchise-like terminology printed on the sheet as implementation requirements. Production game assets should be original, transparent, animation-ready exports created separately.
